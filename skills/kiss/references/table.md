# Table Reference

Use a table when the user needs to compare, scan, or decide.

## Common Tables

### Change Table

| Area | What changed | Why it matters | Risk |
| --- | --- | --- | --- |

### Setup Table

| Step | Action | File or command | Result |
| --- | --- | --- | --- |

### Event Table

| Order | Event | Meaning | Status |
| --- | --- | --- | --- |

### Inventory Table

| Tool | Found | Version | How KISS can use it |
| --- | --- | --- | --- |

## Rules

- Put the table before long prose.
- Use plain labels, not internal jargon.
- Keep cells short.
- Use `Unknown` when evidence is missing.
- After the table, give the user one next step.
